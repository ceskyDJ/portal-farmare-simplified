# Guides

Living guides for complex procedures (deploy, quality checks, multi-step ops). Agents maintain this file.

## Maintenance

- **Append only.** Add a new guide when documenting a complex procedure.
- **Never edit** an existing guide.
- **Remove only** when a guide is no longer relevant.
- To change a guide: **remove** the old entry, then **add** a new entry that reflects the current situation.
- **No merging or averaging** with a dropped entry into a more generalized guide. Each entry stands alone.

## Entry schema

```markdown
### <short title>
**Description:** what it is and why it exists
**When to use:** situations where this guide applies
**How:** concrete steps / how it is used
```
